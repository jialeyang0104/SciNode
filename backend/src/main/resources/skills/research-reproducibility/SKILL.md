# 科研分析与复现检查

1. 确认数据来源、研究对象、分组、观察窗口、变量和结局定义。
2. 区分缺失、未复测、冲突值和来源未知；报告对应数量与处理方式。
3. 明确脚本输入、输出、软件依赖、统计方法、预设比较和多重性处理。
4. 变更队列、终点、定义或主要分析时，输出变更影响与人工确认事项。
5. 保留预设结局的成功、阴性、不利和失败结果；事后分析标为探索性。
6. 输出执行证据、结果摘要、质量检查、复现步骤及科学结论所需的进一步核对。技术检查与科学审核分别记录。
