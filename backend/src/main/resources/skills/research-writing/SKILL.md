# 科研文档修订

1. 根据节点要求修订指定内容，先给结论和证据，再解释范围与局限。
2. 保留关键数字、效应方向、置信区间、阴性和失败结果，采用与证据一致的结论强度。
3. 对新增论断列出来源；依据不足的内容标为待补证据或待人工确认。
4. 输出修改摘要、修订内容、修改依据和待确认项。
5. 任务要求索引补丁时按指定 JSON 结构输出；段落索引、原文与修订文逐项对应，图表结构按原文件保留。
6. 按任务明确要求选择输出格式，并保留原始文件与修订来源。
